# Doc Links Showcase

A small repository whose only job is to exercise **relative Markdown links** in
the Easy Markdown Review reader. Every link form appears at least once:

- sibling links in the same folder,
- parent (`../`) and grandparent (`../../`) links,
- root-absolute (`/…`) links,
- in-page `#anchor` links,
- and links to a non-Markdown file.
