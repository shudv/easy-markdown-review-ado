# Incident response

## Declare

If customer-facing behaviour is degraded, **declare an incident** — do not wait
for certainty. Over-declaring is cheap; under-declaring is not.

## Roles

| Role | Owns |
| --- | --- |
| Incident commander | Decisions, comms cadence |
| Operations lead | Hands on keyboard |
| Scribe | Timeline in the incident channel |

## First five minutes

1. Acknowledge the page.
2. Open the incident channel and pin the dashboard.
3. State the current impact in one sentence.
4. Decide: mitigate now or investigate first.

## Communication

Post an update every 15 minutes even if the update is "no change". Silence reads
as "nobody is working on it".
